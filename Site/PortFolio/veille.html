Qu'est-ce que je surveille ?

Veille technologique

Mon sujet : l'intelligence artificielle au service du développement

Assistants de code, génération automatique, agents autonomes : comment l'IA transforme la façon de concevoir, d'écrire, de tester et de maintenir des logiciels, et ce que cela change pour le métier de développeur.

Comment je fais ma veille ?

Ma méthode

Je combine deux approches complémentaires, puis je trie, résume et archive ce que je trouve.

Pull (je vais chercher)

Je consulte moi-même, à mon rythme, des sources que j'ai choisies : flux RSS, forums, dépôts GitHub, vidéos. C'est une démarche active : je décide quand et quoi lire.

  • Avantage : sources maîtrisées, recherche ciblée
  • Limite : demande de la régularité (30 min, 3 fois par semaine)

Push (l'info vient à moi)

Je reçois automatiquement l'information grâce à des alertes, des newsletters et des abonnements. C'est une démarche passive qui me prévient des nouveautés importantes.

  • Avantage : rien ne m'échappe, gain de temps
  • Limite : risque de surcharge, il faut bien filtrer

D'où vient l'IA pour le code ?

Frise chronologique

Les grandes étapes de l'IA appliquée à la programmation :

2017

Transformer

Google publie « Attention Is All You Need » : l'architecture Transformer, base de tous les grands modèles de langage actuels.

2019

Tabnine

Premier outil d'autocomplétion de code grand public utilisant un modèle de deep learning (GPT-2).

2020

GPT-3

OpenAI dévoile GPT-3 : le modèle sait déjà écrire du code simple à partir d'une description en langage naturel.

2021

GitHub Copilot & Codex

GitHub lance Copilot en préversion, basé sur OpenAI Codex, un modèle entraîné sur du code public. L'IA s'installe dans l'éditeur.

2022

AlphaCode & ChatGPT

DeepMind présente AlphaCode (programmation compétitive). Copilot devient disponible pour tous et ChatGPT sort en novembre : explosion des usages.

2023

GPT-4, Code Llama, Cursor

Les modèles progressent fortement (GPT-4), des modèles de code ouverts apparaissent (Code Llama de Meta) et des éditeurs « IA natifs » comme Cursor émergent.

2024

Premiers agents de code

Annonce de Devin, présenté comme un « ingénieur logiciel IA ». Claude 3.5 Sonnet et Codestral (Mistral) renforcent la concurrence. L'AI Act européen entre en vigueur.

2025

Agents dans le terminal et la CI

Arrivée de Claude Code, du nouvel agent Codex d'OpenAI et de l'agent de codage de GitHub Copilot : l'IA ne complète plus seulement des lignes, elle réalise des tâches entières. Le terme « vibe coding » se popularise.

2026

Aujourd'hui

Les agents de code sont intégrés aux IDE, aux revues de code et aux pipelines. Les enjeux se déplacent vers la sécurité, la vérification du code produit et l'évolution du métier de développeur.

Qu'est-ce que ça change ?

Enjeux & analyse

Productivité

Génération de code répétitif, de tests et de documentation : un gain de temps réel sur les tâches simples.

Sécurité

Le code proposé peut contenir des failles ou des dépendances inexistantes : la relecture et les tests restent obligatoires.

Propriété intellectuelle

Questions sur les licences du code d'entraînement et sur la confidentialité du code envoyé aux services en ligne.

Métier & formation

Le développeur passe de l'écriture à la conception, la vérification et le pilotage d'agents. Bien comprendre les bases reste indispensable.

Mon avis

L'IA est devenue un vrai collègue de travail, mais pas un remplaçant : elle accélère ce que je sais déjà faire et m'aide à découvrir de nouvelles approches. En revanche, je dois toujours comprendre, tester et relire le code proposé avant de l'intégrer.
